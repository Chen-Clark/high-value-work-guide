# 高性价比打工指南

写给所有靠工资过日子的人。从接 offer 到离职，20 节、212 条能直接照做的建议。

在线阅读：https://chen-clark.github.io/high-value-work-guide/

## 这是什么

参考《高性价比人生指南》的写法，把打工这件事里值得留意的规则整理成一份清单：该拿的钱拿到位，不该吃的亏避开。每条一句话，涉及钱和法律的给数字、给边界、给依据；没有硬证据的，标注为"经验判断"。

## 内容

- 接 offer 前怎么算账、合同与试用期、时薪与加班
- 工资、社保、个税、公积金、医保共济
- 加班取证、劳动维权、竞业与离职文件
- 跳槽、加薪、裁员、失业、副业
- 职场关系、通勤、钱袋子、职业健康、情绪管理
